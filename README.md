# EduPath

App para definir objetivos pessoais e acompanhar o caminho até lá.

Cada objetivo tem uma data limite, uma categoria e uma percentagem de progresso que se vai atualizando. Dá para dividir cada objetivo nos passos para lá chegar e ir marcando o que já está feito. Quando o prazo acaba, regista-se se correu bem ou não, com uma nota, e o objetivo passa para o histórico. Assim fica à vista o que já se alcançou e o que se pode fazer melhor.

O que tem:

- painel com os objetivos em curso, os próximos passos e os prazos que estão a chegar
- planos passo a passo para cada objetivo
- avaliação no fim do prazo, com uma nota sobre como correu
- histórico organizado por mês, com a taxa de sucesso geral e por categoria
- notificações dos prazos a chegar e dos objetivos por avaliar
- pesquisa, e filtros por estado e por categoria
- categorias: saúde, carreira, finanças, aprendizagem e pessoal
- contas privadas, em que cada pessoa só vê os seus objetivos; entra-se por convite

Funciona no computador e no telemóvel, em tema claro ou escuro.

Feito com React e TypeScript no site, Python (FastAPI) na API e PostgreSQL na base de dados.

Projeto pessoal, ainda em desenvolvimento.
