# EduPath

Uma app para transformar objetivos pessoais em planos concretos e acompanhar o caminho até lá.

Defines o que queres alcançar e até quando, divides o objetivo em passos, vais registando o progresso e, quando o prazo termina, registas se conseguiste ou não. Tudo fica guardado num histórico, para veres o que já alcançaste e o que podes fazer melhor.

## O que dá para fazer

- **Objetivos com prazo e progresso.** Cada objetivo tem uma data limite, uma categoria e uma percentagem de progresso que vais atualizando.
- **Planos passo a passo.** Divides cada objetivo nos passos para lá chegar e marcas os que já fizeste.
- **Avaliação no fim do prazo.** Quando o prazo termina, registas se o objetivo foi sucedido ou não, com uma nota sobre como correu.
- **Histórico.** Os objetivos avaliados ficam guardados, organizados por mês, com a taxa de sucesso geral e por categoria.
- **Painel.** Um resumo do dia: objetivos em curso, próximos passos, prazos a chegar e o que está à espera de avaliação.
- **Notificações.** Avisos dos prazos que estão a chegar e dos objetivos por avaliar.
- **Pesquisa e filtros.** Encontra qualquer objetivo ou passo, e filtra por estado ou categoria.
- **Categorias.** Saúde, carreira, finanças, aprendizagem e pessoal.
- **Contas privadas.** Cada pessoa só vê os seus objetivos. Para criar conta é preciso um convite.

Funciona no computador e no telemóvel, em tema claro ou escuro.

## Como se usa

1. **Cria um objetivo**: o que queres alcançar, a categoria e a data limite.
2. **Faz o plano**: os passos que te levam até lá.
3. **Acompanha**: marca os passos à medida que os fazes e atualiza o progresso.
4. **Avalia**: no fim do prazo, regista o resultado e o que aprendeste.

## Feito com

React e TypeScript no site, Python (FastAPI) na API e PostgreSQL na base de dados.
